# DevMatrix 研发智能协同平台 —— 领导演示版前端开发任务

你现在要开发的是「DevMatrix 研发智能协同平台」的前端演示版本。

当前目标不是完成正式生产系统，也不是部署 DSH、数据库或真实后端。

当前唯一目标：

**先把完整的产品界面和核心交互做出来，用于给领导演示平台未来的产品形态。**

请直接修改现有 Vue 工程，不要只输出设计方案。

---

# 三、整体产品定位

这不是：

- OA
- ERP
- 普通后台管理系统
- AI 聊天工具
- 数据大屏

它应该让人第一眼感觉：

**这是一个类似 Plane / Linear / GitHub Projects 的现代研发协作平台。**

第二眼发现：

**它与普通项目管理系统最大的区别，是智能体能够直接参与项目、领取任务、执行研发工作并产出交付物。**

产品核心概念：

```text
人 + 智能体
共同完成研发项目
```

# 十二、查看和操作权限必须分开

必须在代码结构中体现：

```text
能看
≠
能编辑
≠
能执行
≠
能删除
```

特别是：

```text
领导能看到下级项目
不代表领导能删除下级项目
```

---

# 十三、删除规则

这是强规则：

```text
只能删除自己创建的内容
```

项目：

```ts
project.createdBy === currentUser.id
```

才能删除。

任务：

```ts
task.createdBy === currentUser.id
```

才能删除。

例如：

```text
张三创建任务
负责人：王五
```

则：

```text
张三：可以删除

王五：不能删除

李经理：不能删除

张主任：不能删除
```

没有删除权限：

**直接不显示删除按钮。**

不要显示灰色禁用删除按钮。

# 五十五、执行要求

1. 检查现有工程
2. 检查现有页面
3. 保留已有可用代码
4. 按以上要求完善
5. 每完成一个主要页面执行 build
6. 修复构建问题
7. 最终统一检查视觉与交互

优先调整现有页面。

不要完全推倒重做，除非现有实现确实无法复用。

**一个可以直接在浏览器中向领导演示的 DevMatrix 研发智能协同平台前端。**
